## Задание 1. Создание класса Point

### Текст задания

Создать класс `Point`, который описывает точку на координатной плоскости. Класс должен хранить координаты X и Y, предоставлять доступ к ним через свойства и иметь возможность выводить информацию о точке в удобном формате.

### Алгоритм решения

В классе `Point` созданы закрытые поля `x` и `y` типа `double` для хранения координат точки. Для доступа к полям реализованы свойства `X` и `Y` с методами `get` и `set`.

Конструктор `Point` принимает две координаты и записывает их в соответствующие поля. Метод `ToString()` переопределён для вывода точки в формате `{x;y}`.

### Тестирование

В методе `Main` создаются три точки с разными координатами. Затем они выводятся на экран. Проверяется правильность создания объектов и формат отображения координат.

## Задание 2. Создание класса Line и работа со ссылками на объекты

### Текст задания

Создать класс `Line`, который представляет линию между двумя точками. Реализовать хранение начала и конца линии, доступ к ним через свойства и вывод информации о линии. Проверить, как изменение координат точек и замена точек влияют на линии.

### Алгоритм решения

В классе `Line` созданы закрытые поля `start` и `end` типа `Point`, которые хранят ссылки на начало и конец линии. Для доступа к ним реализованы свойства `Start` и `End`.

Конструктор принимает две готовые точки и сохраняет ссылки на них. Метод `ToString()` выводит начало и конец линии.

В методе `Main` создаются точки и линии. Затем создаётся третья линия, использующая начало первой линии и конец второй. После этого изменяются координаты некоторых точек, чтобы проверить, как изменения отражаются на линиях, которые используют те же объекты.

В конце начало первой линии заменяется новым объектом `Point`. Это позволяет проверить разницу между изменением координат существующей точки и назначением линии другой точки.

### Тестирование

Проверяется создание нескольких линий, изменение координат точек, использование общих объектов и замена начала линии новым объектом.

## Задание 3. Класс Student и работа с массивами оценок

### Текст задания

Создать класс `Student`, который хранит имя студента и массив его оценок. Проверить разницу между присваиванием одного массива нескольким объектам и созданием копии массива.

### Алгоритм решения

В классе `Student` созданы закрытые поля `name` типа `string` и `grades` типа `int[]`. Для доступа к ним реализованы свойства `Name` и `Grades`.

Конструктор принимает имя студента и создаёт пустой массив оценок. Метод `ToString()` формирует строку с именем студента и его оценками.

В методе `Main` создаются студенты Вася и Петя. Сначала массив оценок задаётся Васе, а затем тот же массив присваивается Пете. Поэтому оба объекта используют один массив, и изменение его элемента через одного студента отражается на другом.

Затем создаётся Андрей, которому передаётся копия массива с помощью метода `Clone()`. После изменения оценки Васи проверяется, что массив Андрея остаётся независимым от общего массива Васи и Пети.

### Тестирование

Проверяется, как изменение общего массива влияет на оценки двух студентов, а также демонстрируется независимость копии массива.

## Задание 4. Перегрузка конструкторов класса Line

### Текст задания

Дополнить класс `Line` конструктором, который принимает четыре координаты: начало и конец линии. Сохранить возможность создания линии с помощью двух готовых объектов `Point`.

### Алгоритм решения

В классе `Line` реализованы два конструктора.

Первый принимает две готовые точки типа `Point` и сохраняет ссылки на них. Второй принимает четыре значения типа `double`: координаты X и Y начала и конца линии. Внутри второго конструктора создаются два объекта `Point`, которые записываются в поля `start` и `end`.

Наличие нескольких конструкторов с одинаковым именем, но разными параметрами называется перегрузкой конструкторов.

В методе `Main` создаются точки и линии двумя способами: по четырём координатам и с помощью уже созданных точек. Затем созданные объекты выводятся на экран.

### Тестирование

Проверяется работа обоих конструкторов и правильность вывода созданных линий.

## Задание 5. Вычисление длины линии

### Текст задания

Добавить в класс `Line` метод `Length()`, который вычисляет длину линии и возвращает целое число. При вычислении запрещается использовать готовые функции извлечения квадратного корня и округления.

### Алгоритм решения

Метод `Length()` вычисляет разницу между координатами конца и начала линии по X и Y. Затем находит сумму квадратов этих разниц, которая используется для вычисления расстояния между двумя точками.

Для нахождения целой части длины используется цикл `while`. Он постепенно увеличивает переменную `result`, пока квадрат следующего целого числа не станет больше полученной суммы.

После этого выполняется ручное округление. Вычисляется число, находящееся посередине между найденным целым числом и следующим. С помощью условия `if` проверяется, нужно ли увеличить результат на единицу.

В конце метод возвращает полученную длину с помощью `return`.

В методе `Main` создаётся линия с координатами начала `(1;1)` и конца `(10;15)`, после чего вызывается метод `Length()` и выводится результат.

### Тестирование

Для линии от точки `(1;1)` до точки `(10;15)` сумма квадратов разниц координат равна 277. После ручного вычисления и округления метод возвращает результат 17.
